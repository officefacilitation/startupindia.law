## 5. Security, Privacy & Regulatory Compliance

### Statutory Compliance Modal (Advocates Act, 1961)
Under the rules of the **Bar Council of India**, advocates are prohibited from soliciting work or advertising. To adhere strictly to Indian statutory ethics:
- On a user's first visit, an uncloseable full-screen overlay modal appears.
- Requires explicit user affirmation that they are seeking information voluntarily.
- Affirms that website access does not construct an advocate-client relationship.
- Persists user consent in browser `localStorage` (`startupIndiaLaw_disclaimerAgreed`).
- If the user clicks **"I DISAGREE"**, they are redirected away to an external neutral domain (`google.com`).
- The modal can be re-inspected at any time via footer links (`window.openDisclaimerModal()`).

### Government Non-Affiliation Declaration
Because the domain is `startupindia.law`, an explicit statutory non-affiliation warning is embedded in the disclaimer modal, site footers, and LLM dossiers:
> *StartupIndia.Law is an independent private practice and is NOT affiliated, associated, or endorsed by the Government of India, the Ministry of Commerce & Industry, DPIIT, or the official `startupindia.gov.in` portal.*

### Serverless Origin Firewall & CORS Isolation
Implemented in both [`/functions/api/submit.js`](functions/api/submit.js) and [`worker.js`](worker.js):
```javascript
function isAllowedOrigin(origin) {
  if (!origin) return true; // Same-origin or non-browser request
  if (origin === "https://startupindia.law" || origin === "https://www.startupindia.law") {
    return true;
  }
  // Allow localhost during development
  if (origin.startsWith("http://localhost:") || origin.startsWith("http://127.0.0.1:")) {
    return true;
  }
  return false;
}
```
- Requests originating from unauthorized foreign origins receive an instant `403 Forbidden` response.
- `OPTIONS` preflight requests are validated and granted minimal required headers (`POST, OPTIONS`).

### Automated Honeypot Bot Trap
All client inquiry forms feature an invisible trap field (`<input type="text" name="website" tabindex="-1" autocomplete="off">`) styled off-screen:
- Automated headless spam scrapers automatically detect and fill all text inputs.
- The server checks if `website` contains any characters.
- If populated, the worker **silently returns HTTP 200 OK** without triggering Resend API calls or notifying firm channels.
- Bots receive a false-positive success confirmation and do not iterate alternative bypass vectors.

### HTML Sanitization & Injection Defense
All inbound user inputs (`name`, `email`, `company`, `phone`, `practiceArea`, `message`) are sanitized through a server-side HTML entity encoder prior to email construction:
```javascript
function escapeHtml(str) {
  return String(str)
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/'/g, "&#039;");
}
```
Prevents Cross-Site Scripting (XSS), HTML injection, and email client rendering vulnerabilities.

### Zero-Exposure Secret Management
- The `RESEND_API_KEY` is never bundled into client-side JavaScript.
- Deployed as an encrypted serverless secret in Cloudflare Pages / Workers.
- In local development, credentials reside in `.dev.vars` (excluded by `.gitignore`) and are loaded strictly in Node server context.

### Fluid Dual-Stage Cursor with Lerp Physics
- Renders an obsidian dot and trailing outer ring.
- Utilizes Linear Interpolation (`lerp = 0.16`) for fluid trailing physics.
- Automatically snaps and scales when hovering over interactive targets (`a`, `button`, cards, inputs).
- Features media query detection (`(pointer: coarse)`) to automatically deactivate on touch and mobile devices.

### Magnetic CTA Hover Physics
- Primary buttons (`#btnHeroConsult`, `#btnHeaderConsult`, `.btn-magnetic`) calculate distance between the cursor and button center.
- Smoothly pulls the button element up to 18% towards the cursor on hover, resetting gracefully on mouse exit.
- Honors `prefers-reduced-motion: reduce`.

### Staggered Scroll Reveal System
- Observes all elements marked with `.reveal-on-scroll`.
- Automatically calculates a cascading transition delay (`(index % 4) * 60ms`) to deliver an editorial cascading entry.

### Contextual URL Query Parameter Prefill
- Allows external links or internal cross-links to pre-populate contact forms:
  - `contact.html?service=Patent+Strategy` automatically matches and selects the corresponding dropdown item.
  - `contact.html?inquiry=Speaking` pre-fills the message text with keynote booking text.
  - Smooth-scrolls to center the contact card automatically.

### Universal Accessible Clickable Cards
- Cards marked with `[data-href]` receive automatic `role="link"` and `tabindex="0"`.
- Supports both click events and keyboard triggers (`Enter` and `Space`), while preserving native bubbling if the user clicks an explicit internal anchor or button.

### Lazy-Loaded Calendly Scheduling Modal
- Consultation buttons trigger a modal overlay.
- The heavy Calendly embed `<iframe>` is **not loaded on initial page load**.
- The iframe src is injected only when the modal is opened for the first time, saving ~350KB of initial page weight.

### Cloudflare Pages & Worker Runtime (`worker.js` & `wrangler.json`)
The application is configured to run on Cloudflare Pages or Cloudflare Workers:
- **`wrangler.json`**: Sets asset directory to `./dist` with `auto-trailing-slash` handling and routes `/api/*` to worker compute first.

### Local Development API Proxy Engine
`vite.config.mjs` contains a built-in development middleware plugin (`localApiPlugin`) that intercepts local `POST /api/submit` requests during `npm run dev`, reads `.dev.vars`, and executes the Cloudflare Worker handler locally. ## 9. API Reference & Data Contracts

### Endpoint: `POST /api/submit`
Handles transactional submission of legal inquiries from the Query Basin and Contact Portal.

#### Request Headers
```http
Content-Type: application/json
Origin: https://startupindia.law
```

#### Request Payload Schema
```json
{
  "name": "Jane Doe",
  "email": "jane@deeptechventure.com",
  "company": "DeepTech Innovations Pvt Ltd",
  "phone": "+91 98765 43210",
  "practiceArea": "Intellectual Property Rights (IPR)",
  "message": "We have developed a novel solid-state battery chemistry and seek PCT claim drafting advice.",
  "website": ""
}
```
*Note: `website` is the honeypot field and must be empty.*

#### Response Schemas

**Success (`200 OK`)**:
```json
{
  "success": true
}
```

**Client Validation Error (`400 Bad Request`)**:
```json
{
  "error": "Name, email, and message are required."
}
```

**Forbidden Origin (`403 Forbidden`)**:
```json
{
  "error": "Forbidden"
}
```

**Server Configuration Error (`500 Internal Server Error`)**:
```json
{
  "error": "Server configuration: RESEND_API_KEY is missing in Cloudflare Worker environment variables."
}
```

### Dual Transactional Email Templates
On successful execution, `/api/submit` dispatches two coordinated emails via Resend:
1. **Internal Firm Notification (`to: info@startupindia.law`)**:
   - High-contrast obsidian letterhead format.
   - Comprehensive table detailing Submitter Name, Verified Work Email, Company/Venture, Phone/WhatsApp, and Selected Practice Area.
   - Distinct styled narrative box displaying the inquiry text.
   - One-click action buttons: *"Reply to Client"* and *"WhatsApp Chat"*.
2. **Client Executive Confirmation (`to: [submitter email]`)**:
   - Editorial ivory letterhead format.
   - Formal acknowledgement from the Office of Aashish (Aash) Gupta.
   - Summary snapshot reiterating their submitted questions and practice area.
   - Reassurance of statutory confidentiality under the Advocates Act, 1961.
   - Direct escalation button linking to the firm's direct WhatsApp line.

## 10. Local Development & Deployment Guide

### Prerequisites
- [Node.js](https://nodejs.org/) v18.0.0 or higher
- `npm` (bundled with Node)

### Installation & Local Execution
```bash
# 1. Clone or navigate to the repository
cd StartupIndiaLaw

# 2. Install development dependencies
npm install

# 3. Start local development server with Vite and API proxy
npm run dev
```
The website will boot at `http://localhost:5173`.

### Environment Variable Setup
For local testing of the `/api/submit` endpoint with live Resend transactional delivery, create or modify `.dev.vars` in the root directory:
```env
RESEND_API_KEY=re_your_test_resend_api_key_here
```

### Production Build & Cloudflare Deployment
```bash
# Compile and optimize static assets into /dist
npm run build
```
Vite generates tree-shaken, minified HTML/CSS/JS bundles into `./dist` in less than 500ms.

#### Deploying via Cloudflare Pages:
1. Connect the Git repository to **Cloudflare Pages**.
2. **Build Settings**:
   - Framework preset: `Vite` (or `None`)
   - Build command: `npm run build`
   - Build output directory: `dist`
3. **Environment Variables**:
   - Add `RESEND_API_KEY` under *Settings > Environment variables*.
4. Cloudflare automatically discovers the top-level [`functions/`](functions/) directory and mounts `/api/submit` as an edge serverless function.

#### Alternative Deployment via Wrangler CLI:
```bash
npx wrangler deploy
```
